# TERMINAL — Thème Shopify Custom

Thème "Copie de Dawn" personnalisé sur la boutique terminal-inter.com

## Fichiers créés

- `assets/terminal-custom.css` — Styles complets + animations scroll
- `sections/terminal-header.liquid` — Header logo TERMINAL à gauche
- `sections/terminal-hero.liquid` — Hero : logo gauche / produit droite
- `sections/terminal-features.liquid` — 4 features voyage
- `sections/terminal-spotlight.liquid` — Mise en avant produit
- `sections/terminal-reviews.liquid` — Avis clients
- `sections/terminal-promise.liquid` — Garanties
- `sections/terminal-cta.liquid` — Call to action final
- `templates/index.json` — Template homepage

## Pour publier

1. Aller sur Shopify Admin > Boutique en ligne > Thèmes
2. "Copie de Dawn" > Actions > Publier
3. Ajouter l'image du sac au produit "Sac de Voyage TERMINAL"
